# Driver SK 👋

An offline-first study app for the Slovak driving-licence theory exam, with the
whole question bank translated into English and Hungarian. It is an
[Expo](https://expo.dev) project (SDK 54, React Native 0.81, expo-router) that
ships to iOS, Android, and — as an installable PWA at
[driver.smartie.team](https://driver.smartie.team) — the web. Bundle id
`com.smartie.driver` on both native platforms.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Configure PostHog (optional)

   Copy `.env.example` to `.env` and fill in your PostHog Project API Key and Host:
   ```bash
   cp .env.example .env
   ```
   
   Get your Project API Key from [PostHog dashboard](https://app.posthog.com) → Project Settings.
   Without these two variables analytics is a no-op and the app runs normally.
   `.env.example` also documents the optional `EXPO_PUBLIC_REVENUECAT_IOS_KEY`;
   `app.config.js` forwards all of them to `Constants.expoConfig.extra`.

3. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)

Expo Go cannot run this project — `react-native-purchases` is not part of its
runtime. Build a dev client with `npx expo run:ios` / `npx expo run:android`, or
run the web target with `npm run web`.

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).

## Scripts

Everything in `package.json`:

| Script | What it does |
|--------|--------------|
| `npm start` | `expo start` — Metro plus the dev menu |
| `npm run ios` / `npm run android` | `expo run:*` — build and install on a simulator, emulator, or device |
| `npm run web` | `expo start --web` |
| `npm test` | Jest suite in `__tests__/` |
| `npm run lint` | `expo lint` (ESLint) |
| `npm run bump:ios` | Bump `ios.buildNumber` in `app.json` before a TestFlight upload |
| `npm run build:web` | Export the PWA into `dist/` and generate its service worker |
| `npm run serve:web` | Serve `dist/` locally with the COOP/COEP headers SQLite-on-web needs |
| `npm run reset-project` | Boilerplate scrubber — see below |

`/ios` and `/android` are gitignored and generated by `expo prebuild`; `app.json`
plus `app.config.js` are the source of truth for native config.

## Get a fresh project

`npm run reset-project` is the `create-expo-app` starter script: it moves
`app/`, `components/`, `hooks/`, `constants/`, and `scripts/` into
**app-example** and leaves a blank `app/` behind. That wipes Driver SK, so it is
only useful if you are reusing this repo as a template.
